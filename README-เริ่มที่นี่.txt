เว็บไซต์กวงเส็ง รถยนต์มือสอง — รุ่นแก้ไขเองได้ (ขาว–แดง–เหลือง)
============================================================

ไฟล์สำคัญ
- index.html: เว็บไซต์สำหรับลูกค้า
- style.css: สีและดีไซน์
- app.js: ระบบหน้าแรก ค้นหารถ หน้ารายละเอียด
- catalog-data.js: ข้อมูลร้านและรถทั้งหมด
- editor.html: หน้าแก้ไขข้อมูลร้าน เพิ่มรถ แก้ราคา ตารางผ่อน
- images/: รูปรถจริง (Toyota Yaris 11 รูป)

วิธีทดลองบนคอมพิวเตอร์
1) แตก ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2) เปิด index.html ด้วย Chrome เพื่อดูเว็บ
3) เปิด editor.html ด้วย Chrome เพื่อแก้ข้อมูล
4) กดปุ่ม "ดาวน์โหลดข้อมูลเว็บไซต์" ใน editor.html
5) นำ catalog-data.js ที่ดาวน์โหลดมาแทนไฟล์เดิมในโฟลเดอร์เว็บไซต์
6) เปิด index.html ใหม่/รีเฟรช จะเห็นข้อมูลที่แก้ไข

วิธีเพิ่มรถคันใหม่
- เปิด editor.html > เพิ่มรถใหม่
- กรอกยี่ห้อ รุ่น ปี ราคา สี เกียร์ เลขไมล์ จุดเด่น
- ถ่ายรูปแล้วตั้งชื่อภาษาอังกฤษ เช่น nissan-almera-01.jpg
- วางรูปในโฟลเดอร์ images และระบุพาธ images/nissan-almera-01.jpg ในช่องรูปภาพ
- ตารางผ่อน ใส่เฉพาะตัวเลขจริงจากไฟแนนซ์ รูปแบบ เงินดาวน์,จำนวนงวด,ยอดผ่อนต่อเดือน
  ตัวอย่างรูปแบบ (ไม่ใช่ข้อเสนอจริง): 30000,60,4500
- บันทึกรถ > ดาวน์โหลด catalog-data.js > แทนไฟล์เดิม

วิธีใส่คลิป YouTube
- editor.html > ข้อมูลร้าน > ลิงก์คลิป YouTube
- วางลิงก์คลิป YouTube ที่เผยแพร่แล้ว เช่น https://www.youtube.com/watch?v=XXXXXXXXXXX
- ดาวน์โหลด catalog-data.js และแทนไฟล์เดิม

วิธีเผยแพร่ฟรีผ่าน GitHub Pages
1) สมัคร/เข้าสู่ระบบ GitHub.com
2) สร้าง Repository ใหม่ (Public) เช่น kuangseng-cars
3) อัปโหลด index.html, style.css, app.js, catalog-data.js และโฟลเดอร์ images
   อย่าอัปโหลด editor.html (เครื่องมือแก้ไขส่วนตัว) หรือไฟล์สำรองข้อมูลที่ไม่ต้องการเผยแพร่
4) เข้า Settings > Pages > Build and deployment > Deploy from a branch
5) เลือก main และ / (root) แล้ว Save
6) รอเผยแพร่และเปิดลิงก์ https://ชื่อบัญชี.github.io/kuangseng-cars/
7) เมื่อแก้ไขข้อมูลจาก editor.html ให้ส่งไฟล์ catalog-data.js ใหม่ไปแทนไฟล์ใน GitHub
   และเมื่อเพิ่มรูปใหม่ ต้องอัปโหลดรูปใน images ด้วย

ข้อจำกัดและคำเตือน
- เว็บไซต์ยังไม่ได้เผยแพร่ขึ้นอินเทอร์เน็ต ไม่มี URL สาธารณะจนกว่าจะอัปโหลดไปยังโฮสติ้ง
- Google Sites ไม่รองรับการอัปโหลดเว็บ HTML ทั้งชุดเป็นเว็บที่แก้ไขด้วย Google Sites โดยตรง
- editor.html เป็นตัวแก้ไขในเครื่อง ไม่ใช่ระบบล็อกอินหลังบ้านออนไลน์
- เว็บไซต์นี้ไม่มีระบบชำระเงินหรือรับจองออนไลน์
- ตารางผ่อนต้องใช้ข้อมูลจริงที่ตรวจสอบแล้ว และขึ้นอยู่กับการอนุมัติสินเชื่อ
- เลขไมล์ Toyota Yaris อ่านจากภาพได้ประมาณ 188,518 กม. ยังต้องยืนยัน
- ลิงก์ YouTube และ Facebook ยังเว้นไว้เพื่อให้ใส่ของจริง
- ไม่ควรเผยแพร่เอกสารส่วนตัวหรือภาพที่มีข้อมูลอ่อนไหวโดยไม่จำเป็น
